# Leo's Personal Website

个人作品集网站 / Personal Portfolio Website

## 关于

这是 Leo（李文浩）的个人网站，展示作为 AI 产品经理的专业技能、项目案例和合作方式。

## 技术栈

- **前端框架**: React 19 + TypeScript
- **构建工具**: Vite
- **样式**: Tailwind CSS
- **动画**: Framer Motion
- **图标**: Lucide React

## 功能特点

- 中英文双语切换
- 响应式设计，支持移动端
- 交互式 Hero 区域（鼠标探索效果）
- 技能分类展示（可折叠）
- 项目案例展示
- 合作方式介绍
- 联系表单

## 运行项目

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 项目结构

```
src/
├── App.tsx          # 主应用组件
├── data.ts          # 数据配置（技能、项目、合作信息）
├── main.tsx         # 入口文件
└── index.css        # 全局样式
```
